# Wrap up

1. Do the `session-checkpoint` steps.
2. List every `[CITE NEEDED]` added this session, with the claim each one needs.
3. Update the `status` field on literature notes read this session (inbox → skimmed → read → core).
4. Add `## Next session` with the first thing to do, in one sentence.
5. Keep today's whole entry under 30 lines.
6. Ask with the question tool whether anything from today should go in `admin/` for the next supervisor meeting: "Yes, add it", "No". If yes, append 2 to 3 bullets to `admin/supervisor-notes.md`.

In the Claude app without a vault: produce one handoff note under 20 lines (goal, done, decisions, open questions and CITE NEEDED items, first thing next time). No preamble, so it's easy to copy.
