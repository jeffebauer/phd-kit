# Start a session

1. Read `CLAUDE.md` and the newest file in `_sessions/`. (In the Claude app without a vault: ask them to paste their last handoff note, or read it from the Project's files.)
2. Summarise in 5 lines or fewer: where things stand, open questions, the suggested next step.
3. Ask for today's goal with the question tool (AskUserQuestion in Claude Code; the multiple-choice tool in the Claude app; plain text otherwise). Offer 2 or 3 options from the log's next steps and open questions. They can type their own.
4. Restate the goal in one sentence. List the notes or citekeys you expect to touch, and which skill fits (for example `find` or `presentation`).
5. If the goal touches many files, suggest plan mode first.
6. Don't open PDFs or run Zotero full-text searches until the plan is agreed.
